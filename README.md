# PSEB — AI Web Engineering 

**Muhammad Shahbaz** 

My practice repository for the **PSEB AI Web Engineering** course. Each file covers one day / one topic of Python, with small tasks at the end.

## Files

| File | Topic |
|---|---|
| `day_04.py` | Variables and data types |
| `day_05.py` | Numbers and string operations |
| `day_06.py` | Lists — create, add, remove, slice |
| `list_vs_tuples.py` | Tuples, and list vs tuple difference |
| `dictionary.py` | Dictionaries with loops |
| `shopping_cart.py` | Task — shopping cart total |
| `student_record.py` | Task — student record and grade |
| `multiplication_table.py` | Task — multiplication table of a number |
